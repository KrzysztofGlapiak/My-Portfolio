# Manual QA Engineer Portfolio - Krzysztof Glapiak

With over 6 years of experience in software quality assurance, I specialize in testing complex business logic, particularly within the iGaming industry. My approach to QA goes beyond standard functional testing. I focus on deep system analysis, risk assessment, and identifying edge cases that often go unnoticed in standard test executions.

I strongly believe that effective manual testing requires an analytical mindset. My daily workflow regularly involves API verification, database state validation, and fundamental security checks to ensure software robustness at every architectural level.

- **API & Network Testing:** Postman, Swagger, Chrome DevTools
